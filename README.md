# GPT / WormGPT staging

This repository is being prepared to store a reviewed copy of the WormGPT-related project.

## Structure

- `wormgpt/` — place the project archive and reviewed source here.
- `SECURITY.md` — handling and disclosure guidance.
- `.gitignore` — excludes credentials, local configuration, and runtime data.

## Important

Do not upload API keys, Telegram bot tokens, passwords, session files, private keys, personal data, or generated memory/configuration files.

Do not run an uploaded archive just because it is stored here. Inspect its contents, dependencies, install scripts, network destinations, and permissions first. Keep untrusted code isolated from personal files and accounts.

The archive itself is not included in this initial setup. Upload it only after reviewing it and confirming that it contains no secrets or harmful payloads.
