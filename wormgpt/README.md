# WormGPT staging area

Upload the reviewed project copy into this folder.

## Suggested layout

- `source/` — reviewed source code
- `archive/` — original archive, if redistribution is permitted
- `docs/` — original documentation and license

Before uploading, check for credentials, private sessions, personal data, malicious install hooks, unexpected executable files, and unsafe network behavior.

Do not place API keys or live account tokens in this folder. Do not enable automatic execution or deployment from this repository.
